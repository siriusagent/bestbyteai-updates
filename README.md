# Best Byte AI Updates Host

Static update metadata for Best Byte AI products.

This repository is public release infrastructure only. It may contain signed
Sparkle appcasts and public release notes. It must not contain private product
source, signing secrets, appcast private keys, service tokens, Apple
credentials, local database files, or developer-machine evidence.

## SiriusMsg Sparkle Feed

```text
https://updates.bestbyteai.com/siriusmsg/appcast.xml
```

The DMG enclosure in the feed points at the public SiriusMsg GitHub Release
asset. The appcast and release notes are signed by Sparkle and must be
regenerated instead of hand-edited.
