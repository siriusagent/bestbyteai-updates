# Sirius 0.1.8

## Use the built-in browser with more kinds of pages

- Browser Use can paste tabular clipboard data into embedded editors and
  spreadsheets. It uses the browser's native Paste command so the page can
  handle the paste itself.
- Browser Use can hold keys and send timed input sequences. It can also check
  for a visible change after an action and capture screenshots at selected
  points in a sequence.

## Answer a question in the composer

When Sirius needs clarification, the question opens above the composer.
Choose an answer or write your own when the question allows it. Sirius keeps
the answer in the conversation when you reopen the chat.

## Connect Messages through SiriusMsg

Connect SiriusMsg from Connected Apps to use Messages in Sirius. SiriusMsg
asks you to approve workspace access to receive attachments and send files.
You can manage those approvals independently. Messages conversations keep
their titles, and supported channels can bring attachments into the transcript.

Requires macOS 26 or later on an Apple silicon Mac.
