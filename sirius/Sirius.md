# Sirius 0.1.8.9 · Build 216

## Sign in once across two screens

Choose a saved login in the Sirius browser and approve it on the email screen. When the site asks for your password, Sirius Security Key fills it automatically. You can then choose **Sign in**. That approval works once, for the same account, website origin, and tab, for up to two minutes.

## Browser uploads

- **Import files through the website’s own picker.** Sirius now activates the button or menu item you see, so sites such as Onshape can start their import before receiving the file. This also works when a site creates a new picker for each upload or accepts several files at once.
- **See what happened when an upload fails.** Sirius distinguishes a click from a confirmed file selection. Feedback reports now preserve the file-selection error codes that help diagnose a failed upload. Passwords and tokens are still redacted.
