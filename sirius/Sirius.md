# Sirius 0.1.8.14 · Build 237

## Pick a model right from the composer

Your connected providers have their own rail, models are searchable, and reasoning levels sit alongside the model list. Browse the options, then choose **Use model** to apply your selection to this chat. Open **More** to set up another provider. The smaller, rounded picker leaves more of the conversation in view.

## Get Ollama and oMLX running from Sirius

Open **Network & Providers → On This Mac** to install or start supported local runtimes. **Update and restart** shows which installation is serving your models, then checks its version once the server is back. If a model requires a newer Ollama version, Sirius checks that model again after the update.
