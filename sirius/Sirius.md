# Sirius 0.1.8.10 · Build 217

## Read Aloud

- **Replies sound more like speech.** Sirius reads headings, lists, and links in a natural order, with pauses between sections. It skips long code blocks by default. Choose **Read All Text** when you want the code too.
- **Choose a voice independently of your chat model.** In **Settings → Voice → Read Aloud**, choose offline Qwen or cloud speech from OpenAI or ElevenLabs. Pick a voice, adjust the speed, and play a sample. Cloud speech sends the prepared text of the reply you choose to play and requires an API key.

## Credentials

- **Set up cloud speech where you use it.** Save the key inline in Voice and manage the same credential in **Credentials & Access**. **Network & Providers** shows the speech connection status. If you already have an API key for the official OpenAI API configured in Sirius, Read Aloud can use it too.
- **Credential sources have readable names.** The catalog shows labels such as **API key**, **Alternate API key**, and **Access token**. Hover over a label when you need the exact lookup name.
