# Sirius 0.1.8.20

- Fixed unwanted scrolling while selecting text in a transcript. Selection and copying also work more reliably across wrapped inline code.
- Fixed a case where connected apps could lose track of a reply while Sirius was still working. With the matching SiriusMsg update, a temporary interruption can recover the saved reply without repeating the turn.
