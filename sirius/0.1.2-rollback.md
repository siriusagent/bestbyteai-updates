# Sirius 0.1.2 has been withdrawn

We are sorry. We shipped Sirius 0.1.2 before it met an acceptable standard of
stability. Builds 157 through 161 exposed too many regressions across startup,
conversation history, session isolation, turn controls, provider state, and
Browser Use. That is our mistake.

Sirius 0.1.2 is unacceptably unstable and has been withdrawn. The recommended
public version is again **Sirius v0.1.1-alpha.031, build 156**.

The features introduced in 0.1.2 are not abandoned. They will be restored only
after extensive testing of signed Release builds, clean installations,
long-running conversations, cross-session boundaries, cancellation races,
provider changes, browser ownership, and the complete public update path.

## If you are already running Sirius 0.1.2

Sparkle cannot automatically install an older build over a newer one. Download
the notarized build-156 installer and replace Sirius manually:

[Download Sirius v0.1.1-alpha.031 build 156](https://github.com/siriusagent/siriusagent/releases/download/v0.1.1-alpha.031/Sirius.dmg)

Please preserve a backup of your Sirius home before replacing the application.
The rollback changes the application; it should not require deleting your
conversations or configuration.

We apologize for the disruption and for the loss of confidence caused by this
release. Shipping this many regressions in succession was not acceptable.
