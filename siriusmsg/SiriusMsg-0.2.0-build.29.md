# SiriusMsg 0.2.0 (build 29)

[Download the branded SiriusMsg installer](https://github.com/siriusagent/siriusmsg/releases/download/v0.2.0-build.29/SiriusMsg-0.2.0-build.29-installer.zip), extract the ZIP, open the DMG, then drag SiriusMsg to Applications.

- When Sirius temporarily stops responding during a turn, SiriusMsg reconnects and checks the saved result for that same turn. If the reply is ready, SiriusMsg can deliver it without starting the turn again.
- If SiriusMsg still cannot verify the turn, Needs review identifies the step that failed. Unconfirmed Messages sends still require review.

This is an alpha release. Sirius connections require approval in Sirius.
